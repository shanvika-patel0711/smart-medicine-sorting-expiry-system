# Hardware components

The following list describes the hardware documented for the submitted four-slot prototype.

- Arduino UNO
- Four green LEDs (slot occupancy indicators)
- Four red LEDs (highest-priority slot indicators)
- One white LED (power indicator)
- Buzzer
- Two push buttons: DISPENSE and NEXT
- Breadboard
- Jumper wires
- Current-limiting resistors for the LEDs
- Four-slot medicine storage tray

No physical barcode scanner, RTC, DHT sensor, HX711 module, SD card module, or servo motor is claimed as part of this implemented version. Some of these appear as possible future enhancements in the academic report.
